# 🎮 so_long

A simple yet engaging 2D tile-based game developed using **MiniLibX**, where the player must collect all collectibles and escape the map.

> _"So long, and thanks for all the fish!"_

---

## 🎯 About the Project

**so_long** is a 2D graphical project written in **C** using **MiniLibX**, the simple graphics library provided by 42 School. The goal is to:

- Collect all items
- Avoid enemies (optional/bonus)
- Reach the exit using the shortest possible path

---

## ✨ Features

### Mandatory:

- 2D map rendering using MiniLibX
- Map validation (walls, rectangular shape, characters)
- Path validation (BFS/DFS)
- Movement counter in the terminal
- Key controls for movement (W, A, S, D)
- Clean game exit on ESC or window close
- Error handling with clear messages
